PROBLEMATIKA & URGENSI
Latar Belakang & Transformasi Digital RT

1. Pembukuan Kas Manual

Masalah: Pencatatan kas di buku tulis fisik rawan hilang, rusak, atau terjadi selisih saldo. Warga tidak memiliki akses langsung untuk memantau dana kas.

Solusi E-KASRT: Dashboard pembukuan terbuka real-time dengan bukti kwitansi sah dan grafik arus kas bulanan.

2. Antrean Panjang Posyandu

Masalah: Pencatatan manual kehadiran balita dan penimbangan BB/TB memakan waktu, antrean menumpuk, dan kartu KMS rentan rusak.

Solusi E-KASRT: Presensi mandiri via tap e-KTP ibu balita (ESP32 RFID) dalam 1 detik disertai cetak KMS elektronik.

3. Penagihan Iuran Lambat

Masalah: Pengurus harus mendatangi rumah warga satu per satu atau mengecek buku tebal untuk mengetahui siapa yang belum membayar.

Solusi E-KASRT: Loket e-KTP mandiri. Tempel kartu langsung kelihatan status Lunas / Belum Bayar dan tombol Quick Pay.

EFISIENSI LOKET PELAYANAN
Loket Tap e-KTP: Verifikasi Iuran & Quick Pay

Alur Transaksi Loket Mandiri

  • Langkah 1 (Tap Kartu): Warga menempelkan e-KTP pada perangkat pembaca di meja sekretariat RT.
  • Langkah 2 (Deteksi Cepat): Layar website seketika memunculkan nama warga, blok/nomor rumah, dan status tagihan bulan ini.
  • Langkah 3 (Verifikasi Status): Jika sudah bayar, muncul badge hijau "LUNAS". Jika belum bayar, muncul status "BELUM BAYAR (Rp 50.000)".
  • Langkah 4 (Quick Pay 1-Klik): Pengurus mengklik tombol Quick Pay; sistem mencatat pelunasan, menerbitkan kwitansi, dan membukukan kas masuk secara otomatis.

Keunggulan Inovasi Loket

  • Zero Manual Search: Petugas tidak perlu lagi mengetik atau mencari nama warga dari ratusan baris data.
  • Akurasi Data Kependudukan: Nomor UID kartu terikat langsung dengan NIK kependudukan warga yang bersangkutan.
  • Sinkronisasi Instan ke Pembukuan: Transaksi iuran langsung tercatat ke dalam arus kas masuk RT tanpa rekonsiliasi malam hari.
  • Dukungan Kartu Fleksibel: Mendukung e-KTP nasional, kartu RFID Mifare 13.56MHz, dan gantungan kunci RFID.

DEVOPS & MANAJEMEN DATABASE
Pusat Kendali Migrasi & Database Kas RT

1. Status Migrasi Skema Live

  • Inspeksi seluruh file migrasi Laravel di folder database.
  • Badge visual informatif: Sudah Berjalan vs Pending.
  • Informasi nomor Batch dan tanggal eksekusi.
  • Tombol Jalankan Migrasi (php artisan migrate --force) langsung di web.

2. Inspeksi 26 Tabel Sistem

  • Pelacakan jumlah baris record riil dari setiap tabel.
  • Perhitungan ukuran penyimpanan database dalam KB / MB.
  • Informasi Storage Engine InnoDB dan Collation UTF-8.
  • Badge status: Terisi Data vs Kosong (0 Record).

3. Seeder & Real SQL Backup

  • Tombol Isi Data / Seeder 1-klik untuk mengatasi database kosong saat pertama deploy ke VPS.
  • Tombol Download SQL Backup riil (Create Table + Insert Data) siap restore kapan saja.
  • Dilengkapi proteksi aman FOREIGN_KEY_CHECKS=0.

Keunggulan Firmware ESP32 v4.1

  • Auto-Detection Pin RST: Firmware secara otomatis mendeteksi kabel RST apakah tersambung di GPIO 22 atau GPIO 25 saat booting.
  • Penguatan Antena Maksimal (48dB): Menyetel register RFCfgReg (0x70) sehingga e-KTP terbaca lebih sensitif dan responsif.
  • Direct Web Serial USB: Tanpa instalasi driver tambahan, langsung terbaca di browser Google Chrome / Edge.
  • Wi-Fi HTTP Client Fallback: Tetap mendukung koneksi nirkabel jika perangkat diletakkan jauh dari laptop operator.
